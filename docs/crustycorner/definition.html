Definition

crusty corner, n. A corner that, when describing it, one may consider crusty. Also used in football-style chants to amuse Thomas. See also: slitchy.

slitchy, adj. A portmanteau of 'slimy' and 'itchy'. Can be used to describe one's crusty corner.
